# Перед стартом

Папка содержит материалы для обеих игр и инструмент для выгрузки токенов. Первый этап заканчивается локальной сборкой и проверкой в браузере.

1. Открой в Codex **папку, в которой лежит этот файл**, и создай в ней новый обычный чат. До первого сообщения выбери GPT-6.2-Sol, уровень рассуждения High и стандартную скорость. Для основной реализации это даёт модели больше возможности обдумать связанные решения — язык объявления, сохранение версии и автозамену. Фактический расход покажет журнал. Свежий чат даст разработке собственный счётчик с первого запроса. [Выбор модели в Codex](https://learn.chatgpt.com/docs/models) · [Режимы рассуждения](https://developers.openai.com/api/docs/guides/reasoning)
2. Вставь содержимое [START-PROMPT.txt](START-PROMPT.txt) целиком **первым сообщением**. Если хочешь поменять объём работы, внеси правку в файл до отправки. Полный текст нужен, чтобы сохранить точное начало разработки.
3. Когда чат закончит сборку, открой присланный адрес localhost. Проверь переключатель RU / EN, редактирование и экспорт баннера, согласование и подбор замены.
4. После твоей локальной проверки останется отдельный этап для сдачи работодателю — открыть доступ к исходникам и опубликовать приложение. Его можно выполнить самостоятельно или отдельным сообщением поручить чату.

## Что открыть

- [Превью на русском](starter/preview.jpg) и [на английском](starter/preview-en.jpg) показывают четыре комбинации. Готовые баннеры 1080 × 1080 лежат в [examples](starter/examples/), английские версии — в [examples/en](starter/examples/en/). [Исходные слои](starter/art/) общие для обоих языков.
- Восемь концепций содержат заголовок, основной текст и кнопку в каждой языковой версии. [Тексты RU](starter/AD-COPY.md) · [English copy](starter/AD-COPY.en.md) · [Каталог и условия акций](starter/catalog.json) · [Словарь интерфейса](starter/ui.json)
- Переключатель RU / EN в шапке меняет язык рабочего места. Язык объявления выбирается в брифе, поэтому можно работать с английским баннером в русском интерфейсе. При автозамене черновик наследует язык исходного объявления.
- В [демостатистике](starter/demo-metrics.json) у объявления A для Survivalist 400 кликов и 40 установок при расходе 240 €, у B 240 кликов и 80 установок при тех же 240 €. При цели 4 € за установку кнопка проверки предложит замену A. Объявление Stories только запущено. За один закрытый день накопились 900 показов и две установки, статус — «Мало данных».
- [Промпты изображений](starter/image-prompts.json) позволяют воспроизвести замысел. Иллюстрации, персонажи, рекламные сюжеты и цифры подготовлены для независимой демонстрации. Названия и жанры обеих игр сверены с [каталогом GamesBoost42](https://gamesboost42.games/).

## Как получить фактический лог

На этом компьютере Codex Desktop автоматически сохраняет показания модели в локальный журнал чата. Скрипт проверен на фактических данных этой подготовительной переписки. По возможности он читает token_usage_record с расходом каждого ответа и накопительным счётчиком чата. В версиях с событиями event_msg.token_count он выгружает предоставленные приложением накопительные показания. Для работы нужен системный python3, дополнительных пакетов нет. Об уведомлениях со статистикой чата см. [документацию Codex](https://developers.openai.com/codex/app-server/).

Новый чат первой командой привяжет свой идентификатор через `python3 tools/export-usage.py start`. Команда только выбирает журнал. Codex начинает считать уже с первого запроса. Локальная привязка находится в исключённой из Git папке `.usage-local/`.

**После последнего ответа чата о локальной сборке** открой терминал в папке проекта и выполни одну команду. Это включает расход последнего ответа и само по себе не обращается к модели.

```sh
python3 tools/export-usage.py
```

Для сдачи приложи `evidence/development/usage.jsonl` (события с отметками времени), `evidence/development/summary.json` (итог и время среза) и `evidence/initial-prompt.txt`. Обновлённые файлы можно приложить напрямую или закоммитить и отправить в репозиторий. Если после выгрузки попросишь AI исправить проект, повтори команду после последнего ответа. Текст переписки, пути до личных журналов, ключи и содержимое вызовов инструментов в выгрузку не попадают.

Число для отчёта — `usage.total_tokens` из итогового JSON. Накопительные строки суммировать нельзя. Кэшированные входные и токены рассуждения уже входят в соответствующие счётчики. Токены и денежные списания — разные величины.

[Подготовительный снимок](evidence/preparation/summary.json) и [пояснение к нему](evidence/preparation/NOTE.md) можно приложить отдельно и явно назвать подготовкой материалов. Снимок охватывает обсуждение и работу этого чата по указанное время. Встроенная генерация иллюстраций вернула файлы без отдельной цифры токенов каждой картинки. Во время работы готового прототипа обращений к модели по проектному решению будет ноль.
