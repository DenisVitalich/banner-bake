# Banner Bake

[Открыть демо](https://banner-bake-production.up.railway.app/)

**«Создать вариант»** → выберите игру, тип «Анонс» и хотя бы одну площадку → **«Сгенерировать»** → выберите карточку → **«Запустить в демо»** → **«Подтвердить запуск»**.

После подтверждения откроется раздел **«Объявления»**, где появится созданное объявление.

Локальная мастерская рекламы игр Survivalist: Invasion и Stories: Your Choice. Бриф, черновики, демозапуск и статистика доступны на русском и английском. Баннер 1080 × 1080 собирается на сервере из локальных слоёв и текстов.

## Сценарий проверки

1. Нажмите **«Создать вариант»**. Выберите игру, тип «Анонс» и хотя бы одну площадку.
2. Нажмите **«Сгенерировать»** и выберите карточку с баннером и текстом.
3. Нажмите **«Запустить в демо»**. Проверьте объявление в предпросмотре и нажмите **«Подтвердить запуск»**.
4. В разделе **«Объявления»** появится созданное объявление и уведомление об успешном запуске. Нажмите на заголовок объявления, чтобы открыть предпросмотр и управление показом.

### Скачивание баннера или поста

Если нужен файл, в предпросмотре редактора выберите формат и нажмите «Скачать». Доступны баннер PNG, весь пост HTML со встроенным баннером и текст TXT. HTML открывается локально в браузере.

### Проверка демообъявлений

В «Объявлениях» выберите Survivalist: Invasion. Стартовые объявления на английском. У «Watchtower · scout» CTR 2 %, у «Watchtower · landscape» — 1,2 %. Оценка показывает фактическую долю установок от кликов за два закрытых дня. Для Stories пока мало данных.

Найдите «What’s in your pack?» с подписью «Watchtower · scavenging». CTR этого демообъявления 0,3 % при 1,6 % у сопоставимых объявлений той же кампании. Нажмите «Перегенерировать», чтобы открыть черновик с другим текстом и композицией. Можно отредактировать исходный вариант вручную. После подтверждённого запуска новый вариант начинает сбор статистики с нуля, а предыдущая версия сохраняет свои метрики.

Демоподсказка появляется у активного объявления, если в каждом из двух закрытых дней было достаточно показов, а CTR составил меньше половины CTR сопоставимых объявлений той же кампании. Повторное действие открывает ранее созданный черновик для этого периода.

Кнопка ↻ рядом с пометкой «Демо» после подтверждения возвращает исходный список объявлений. Текущие объявления и их версии удаляются, настройки каталога и загруженные изображения сохраняются.

Редактор сохраняет настройку автоматической перегенерации вместе с креативом. Для рабочей версии по этой настройке фоновый воркер сможет проверять реальные метрики и готовить новые варианты. В демо черновик создаётся по нажатию кнопки в оценке.

## Настройки и аналитика

Шестерёнка открывает настройки игр, тем, сцен, персонажей и типов публикаций. Изменения сохраняются в локальной базе. Удаление скрывает вариант из новых брифов и сохраняет его для объявлений, которые уже на него ссылаются. Новый креатив начинается без картинки. Выберите сцену, загрузите файл или примените сгенерированный вариант. При выборе нескольких площадок в предпросмотре появятся переключатели их макетов.

Язык объявления задаётся в брифе. Язык и тема интерфейса переключаются в шапке и сохраняются в браузере.

В разделе «Аналитика» можно выбрать произвольный период или последние 7, 30 и 60 дней, посмотреть сводные показатели и графики по дням и играм. Аналитика использует 90 дней сводных демоданных для двух стартовых игр.

«Предложение» в брифе описывает конкретную выгоду, например скидку. «Основной текст публикации» содержит обращение к игрокам. Приложение объединяет его с предложением, условиями розыгрыша и сроками из брифа в готовый пост.

## Локальный запуск

Нужен Node.js 24. Выполните команды в папке проекта.

```sh
npm ci
npm run check
npm run build
npm run start -- --hostname localhost --port 3000
```

Откройте [http://localhost:3000](http://localhost:3000). SQLite хранит версии, загруженные картинки и собранные PNG в `.data/creative.sqlite`. Папку данных можно задать переменной `DATA_DIR`. Рабочее пространство привязано к cookie браузера. Для проверки сохранности после перезапуска откройте приложение в том же профиле браузера. Для демонстрации на исходных данных используйте новое приватное окно.

Генерация подбирает варианты из локального каталога, а кнопка запуска меняет статус в демо. Для локального запуска достаточно Node.js и материалов репозитория. При запуске в контейнере подключите том к `/data`, чтобы SQLite и загруженные файлы пережили замену контейнера.

## Модели и журнал

- Локальная доработка и проверка в текущем чате Codex выполнены на GPT-6.2 Sol с уровнем рассуждения `xhigh`. Исходная заготовка приложения уже была в папке проекта при старте чата.
- Для подготовки материалов использован GPT-6.2 Astra с уровнем `max` и встроенный ImageGen для семи иллюстраций. Работа приложения выполняется локально на Next.js, SQLite и Sharp.
