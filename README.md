# Banner Bake

Локальная мастерская рекламы игр Survivalist: Invasion и Stories: Your Choice. Бриф, черновики, демозапуск и статистика доступны на русском и английском. Баннер 1080 × 1080 собирается на сервере из локальных слоёв и текстов.

## Запуск

Нужен Node.js 24. Выполните команды в папке проекта.

```sh
npm ci
npm run check
npm run build
npm run start -- --hostname localhost --port 3000
```

Откройте [http://localhost:3000](http://localhost:3000). SQLite хранит версии, загруженные картинки и собранные PNG в `.data/creative.sqlite`. Папку данных можно задать переменной `DATA_DIR`. Рабочее пространство привязано к cookie браузера. Для проверки сохранности после перезапуска откройте приложение в том же профиле браузера. Для демонстрации на исходных данных используйте новое приватное окно.

Генерация подбирает варианты из локального каталога, а кнопка запуска меняет статус в демо. Для локального запуска достаточно Node.js и материалов репозитория. При запуске в контейнере подключите том к `/data`, чтобы SQLite и загруженные файлы пережили замену контейнера.

## Сценарий проверки

1. Откройте «Объявления» и выберите Survivalist: Invasion. CTR объявления A составляет 2 %, B — 1,2 %. Оценка показывает фактическую долю установок от кликов за два закрытых дня. Для Stories пока мало данных.
2. В редакторе выберите площадки и сохраните черновик или нажмите «Запустить в демо». Подтвердите запуск в окне с баннером и постом. Приложение откроет список объявлений и покажет уведомление. Нажатие на название объявления в списке открывает предпросмотр и управление показом.
3. В редакторе нажмите «Сгенерировать», выберите вариант и скачайте баннер PNG, весь пост HTML или текст TXT. HTML открывается локально и содержит встроенный баннер. Язык объявления задаётся в брифе. Язык и тема интерфейса переключаются в шапке и сохраняются в браузере.

Шестерёнка открывает настройки игр, тем, сцен, персонажей и типов публикаций. Изменения сохраняются в локальной базе. Удаление скрывает вариант из новых брифов и сохраняет его для объявлений, которые уже на него ссылаются. Новый креатив начинается без картинки. Выберите сцену, загрузите файл или примените сгенерированный вариант. При выборе нескольких площадок в предпросмотре появятся переключатели их макетов.

В разделе «Аналитика» можно выбрать произвольный период или последние 7, 30 и 60 дней, посмотреть сводные показатели и графики по дням и играм. Аналитика использует 90 дней сводных демоданных для двух стартовых игр.

«Предложение» в брифе описывает конкретную выгоду, например скидку. «Основной текст публикации» содержит обращение к игрокам. Приложение объединяет его с предложением, условиями розыгрыша и сроками из брифа в готовый пост.

## Модели и журнал

- Локальная доработка и проверка в текущем чате Codex выполнены на GPT-6.2 Sol с уровнем рассуждения `xhigh`. Исходная заготовка приложения уже была в папке проекта при старте чата.
- Для подготовки материалов использован GPT-6.2 Astra с уровнем `max` и встроенный ImageGen для семи иллюстраций. Работа приложения выполняется локально на Next.js, SQLite и Sharp.
