# Подготовка материалов

Здесь лежат фактические показания **подготовительного чата** по момент `through_utc` в [сводке](summary.json). Сюда попало раннее обсуждение задания и подготовка стартового комплекта. Это отдельный этап. Для разработки нового приложения предназначен собственный каталог `evidence/development/`.

[Строки выгрузки](usage.jsonl) содержат только показания Codex и время. Для источника `token_usage_record` поле `usage` описывает один ответ, а `thread_token_usage` — накопительный результат. Итог в сводке взят из последнего накопительного показания. Флаг `response_sum_matches_thread_total` позволяет проверить, совпадают ли с ним суммы по отдельным ответам.

В этом чате сделано семь запросов встроенному ImageGen и получено семь исходных PNG. Четыре фона и три прозрачных персонажа перечислены в [исходных промптах](../../starter/image-prompts.json). Инструмент вернул изображение без отдельной разбивки токенов или цены. В отчёте это «нет отдельных данных». Из тех же слоёв локально собраны четыре примера баннеров в каждом языке.
